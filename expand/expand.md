**1. Why some developers dislike JavaScript's async, loose typing, and web platform:**

- **Async:** It can be confusing when things don’t run in the order you expect. Developers must understand callbacks, promises, and async/await.
- **Loose typing:** JavaScript allows any variable to change type, which can cause unexpected bugs if you're not careful.
- **Web platform:** Not all browsers behave the same way, so JavaScript code may work in one but break in another.

---

**2. Why was JavaScript made loosely typed and asynchronous?**

JavaScript was made to be easy to learn and quick to use. Loose typing lets you write code faster without defining every variable type. Async behavior helps web pages stay fast and responsive without freezing when waiting for things like network requests.

---

**3. Compiled vs Interpreted – and what is JavaScript?**

- **Compiled** languages like C++ are turned into machine code before they run.
- **Interpreted** languages like JavaScript run line-by-line in the browser.
JavaScript is interpreted, so it runs immediately but may be slower than compiled languages. It’s great for web development because it doesn’t need a compiler.

---

**4. Why are we focusing on vanilla JS (no frameworks)?**

Learning plain JavaScript first helps you understand how things work under the hood. Once you’re comfortable with JS, using frameworks becomes easier. If you skip vanilla JS, you might rely on tools without understanding what they do.

This lab teaches how to debug code, plan website behavior with diagrams, and work with GitHub. These are important for teamwork, troubleshooting, and organizing project tasks in the final website or app.
